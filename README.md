# Bike Sharing Demand Analysis

## Project Overview
Analyzed bike-sharing rental data using Microsoft Excel and Power Query to identify rental patterns and demand trends.

## Datasets
- Dataset 1: Bike-sharing rental and time-related records.
- Dataset 2: Weather information, including temperature, humidity, and wind speed.
- Dataset 3: Additional bike-sharing records.

## Data Cleaning
- Handled missing values.
- Checked duplicate records.
- Corrected data types.
- Merged and appended datasets using Power Query.

## Tools Used
- Microsoft Excel
- Power Query
- PivotTables and PivotCharts
- Interactive Dashboard
- Forecasting
- Anomaly Detection

## Key Analysis
- Weather-wise rental analysis
- Hourly and date-wise demand
- Temperature and humidity analysis
- Correlation analysis
- Demand forecasting
- Anomaly detection

## Project Outcome
Identified bike rental patterns to support demand planning and resource allocation.
